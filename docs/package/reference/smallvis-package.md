# Small Scale Neighborhood Embedding Algorithms

Neighborhood embedding methods for exploring dimensionality reduction on
small datasets. See
[`smallvis`](https://jlmelville.github.io/smallvis/package/reference/smallvis.md)
to create an embedding.
